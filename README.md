# CookedUI TV

A lightweight Android TV launcher experiment with a dark interface, cyan focus highlight, installed-app discovery, and D-pad navigation.

## Build

GitHub Actions builds a debug APK on every push to `main` and on manual workflow dispatch. Open the repository's **Actions** tab, select **Build CookedUI TV APK**, open a successful run, and download the `CookedUI-TV-debug-APK` artifact.

The TV firmware may restrict changing the default Home launcher. This project is not tested on every TV model.
